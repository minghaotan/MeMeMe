# MeMeMe
这是一个用于中国大陆公民存放个人隐私的服务，后端部署于家庭内网服务器，客户端基于Tauri构建的跨平台IOS和安卓。
数据存储双层结构，APP内部基于sqlite存储，每个数据块包含独立时间戳。
当检测到内网链接时，可进行数据同步。数据块Id相同基于时间戳保存，不同则都保存在服务器，app也能从服务器获取缺失的数据块。
数据块同步服务器后无法删除，但是可以添加隐藏、作废等标签，用于默认不展示的逻辑。
客户端初始化会强制设置密码，不能是简单密码，错误会锁定，阶梯锁定时间。
客户端敏感数据加密保存。

也用来做一个家庭云

有内网服务器公开内容，比如照片。所有人打开后会获得一个副本。断网也能浏览。（本质就是一堆照片和meta信息）。
